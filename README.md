# Engage Ed

An archived Express and MongoDB prototype for an educational question platform.

## Local setup

1. Install dependencies with `npm install`.
2. Copy `.env.example` to `.env`.
3. Set `DATABASE_URL` to a development MongoDB database.
4. Run the service with `npm run dev`.

## Security note

Environment files and generated dependencies are intentionally excluded from version control. This repository is retained as an archived project and is not actively maintained.
